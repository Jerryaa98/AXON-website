AXON Supportive Token Revealing for Fast Diffusion Language Model Decoding

A training-free plug-in for diffusion language models. When parallel decoding stalls, AXON reveals anchors: confident masked tokens that uncertain positions attend to, giving the rest of the sequence the context it needs.

Giries Abu Ayoub1, Mario Barbara1, Lluís Pastor-Pérez2, Tanja Bien2, Aneesh Barthakur2, Alaa Maalouf1, Loay Mualem2,3

1Department of Computer Science, University of Haifa  ·  2Institute for AI, University of Stuttgart  ·  3IMPRS-IS

Paper Code Talk Poster

How AXON works

Gate → select anchors → reveal supportive context.

A lightweight gate checks every denoising step. When uncertain tokens lack support, AXON picks anchors with a submodular coverage objective and reveals them; otherwise the base decoder's proposal goes through unchanged.
